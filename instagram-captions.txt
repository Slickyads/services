============================================================
THE FORMULA (15 tags per post for 2026)
============================================================

Use the full SET 1 (15 tags) on most client-acquisition posts. Switch
to SET 2/3/4 when posting vertical-specific content.

- 4-5 Dubai + UAE intent tags (reach + targeting)
- 4-5 industry-specific tags (relevance)
- 3-4 buyer-intent tags (qualified traffic)
- 1-2 niche long-tail (low volume, high intent)
- 1 branded: #SlickyMedia


============================================================
WHAT TO AVOID
============================================================

- Banned/shadow-banned tags: #entrepreneur #business #marketing (overused in 2026)
- Generic low-intent tags: #BusinessEssentials #smallbusinesssupportingsmallbusiness
  (won't reach your ideal UAE clients)
- 30+ tags (Instagram treats this as spam)
- Tags in the first line (crushes readability)
- Same set every post (algorithm limits reach)
- Duplicates within a post (e.g. #Dubai and #DubaiBusiness counted twice in
  Instagram's eyes — pick one or the other)


============================================================
ROTATION & TRACKING
============================================================

Make 3-4 versions of your hashtag set and rotate them across posts.
After 2-3 weeks, check Instagram Insights → Posts → sort by reach to
see which tags actually drove impressions. Drop the bottom 20% and
double down on winners.

For multi-vertical accounts, test SET 1 (core) against the relevant
vertical-specific set (2/3/4). Vertical sets usually win on qualified
reach, core set usually wins on raw impressions.
