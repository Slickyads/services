# Slicky Media - Digital Marketing Agency

## Project Overview
Landing page for Slicky Media (slickymedia.com) - a digital marketing agency based in UAE offering Google Ads, Meta Ads, SEO, Social Media Management, and Shopify services.

## Tech Stack
- Static HTML + CSS (no build process)
- Cloudflare Pages deployment
- GitHub for version control
- Google Tag Manager (GTM-58ZPXKF) tracking

## Key Pages
- `index.html` - Main landing page with lead capture form

## Services Offered
1. Google Ads Management
2. Meta Ads (Facebook & Instagram)
3. SEO Services
4. eCommerce / Shopify Growth
5. Social Media Management
6. Digital Project / Traffic Management

## Client Info
- Target: Businesses spending AED 5k-75k+/month on ads
- Fee: 10-20% of ad spend
- ROAS: 3-4x average
- Clients: 20+

## Form Fields
- Name, Phone, Service Needed, Budget Range, Message
- Form sends via WhatsApp to Slicky Media

## Deploy Details
- Cloudflare Pages project: services.slickymedia.com
- Build: None (static files)
- Output directory: `/`
- GitHub repo: https://github.com/Slickyads/services
