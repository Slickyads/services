# Slicky Media Landing Page

Landing page for Slicky Media digital marketing services. Built with static HTML/CSS.

## Project Structure
- `index.html` - Main landing page with form and service offering
- `styles.css` - Stylesheet (not in this repo - see root)
- `assets/` - Images and icons

## Key Features
- Hero section with value proposition
- Service offerings (Google Ads, Meta Ads, SEO, Social Media)
- Lead capture form with WhatsApp integration
- Responsive design (mobile-first)
- Google Tag Manager tracking

## Deployment
Push to GitHub and deploy via Cloudflare Pages.
Build: No build step needed (static HTML).
Output: Root directory files.

## Development
- Edit `index.html` for content changes
- Ensure mobile-first responsive design
- Test form submissions
